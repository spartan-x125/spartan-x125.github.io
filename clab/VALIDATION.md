## 自动化计算验证

`npm test`：26 项测试全部通过。

| 覆盖 | 验证依据 |
| --- | --- |
| 输入与复数 | 幂与一元负号优先级；惰性 If；希腊别名；sqrt/ln/arg 主值；保留名、非法字符和数学域错误 |
| FFT / 卷积 | 复数 FFT 往返；小序列卷积与手算 [1,5,6] 一致；线性卷积长度正确 |
| 依赖 | 只修改 a 后重算 a/x/y，独立分支复用；隐藏 x 不影响 y；多轮缓存重用有效 |
| 失败状态 | 未定义变量、循环、重复命名、连续与离散混用、奇点与负采样率均报告错误 |
| 连续卷积 | 因果阶跃与指数响应在多个时刻对照 1−exp(−t/tau)，容差 0.011，覆盖矩形积分网格误差 |
| 理想冲激 | delta(t)+0.4delta(t−d) 与复指数的解析加权时移逐点一致；冲激乘积和非线性自变量拒绝 |
| 频谱 | 有非零时间起点的 5 Hz 余弦幅值 0.5，复指数幅值 1；时间起点相位正确 |
| 逆变换 | Fourier 正逆往返逐点一致；任意频率函数可生成有限 IFFT 输出 |
| 频域滤波 | 5 / 12 Hz 双音经 8 Hz 低通，中央半窗口输出对照低音分量 RMS < 0.07，单独承认边缘截断 |
| 离散卷积 | [1,2,3] 与 [1,0.5] 对照 [1,2.5,4,1.5]；未知采样率不标 Hz |
| 采样与副本 | 1 kHz 在 1.5 kHz 采样时与 0.5 kHz 序列一致；采样元数据保留，谱覆盖观察频率范围 |
| 升余弦 | 原点、可移除奇点及不同滚降下整数符号零点；成形后对齐采样恢复输入符号 |
| 匹配滤波 | 有限矩形脉冲在 T 处峰值与脉冲能量一致，容差 0.002 |
| 调制与噪声 | 无噪声 BPSK/QPSK 恢复比特；单位符号能量；奇数比特 QPSK 拒绝；固定种子复现，Eb/N0 增加 20 dB 后同噪声样本缩小 10 倍 |
| 随机源 | 40000 个标准正态样本，均值容差 0.025、方差容差 0.04 |
| 场景 | 全部 39 个预设经同一引擎计算；改名更新引用；JSON 恢复；非法颜色与超量点数拒绝 |
| 熵与互信息 | 确定信源、等概率分布、独立信道与确定信道极限；非法概率拒绝 |
| 容量 | 固定总功率与固定接收 SNR 分别验证；BSC 的 p=0/0.5/1；宽带极限 |
| Huffman | 前缀性质、平均码长与熵界、并列权重的确定顺序、唯一有效符号约定 |
| 汉明码 | 16 个消息分别验证无错误及 7 种单错；G/H 正交、最小距离 3、双错误纠边界 |
| CRC | 1011 / 1101 手算码字 1011100；每位单错检出；生成多项式倍数漏检示例 |
| 卷积码 / Viterbi | 手算固定 (7,5)₈ 输出；Viterbi 路径与小规模穷举全部候选的最短度量一致 |
| LFSR | 非零 7 状态周期、已知输出 0010111、归一化循环相关、异或扰码与恢复 |
