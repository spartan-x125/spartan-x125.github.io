# Clab · 通信原理实验室

主界面只有两个板块：**计算器**与**概念辨析**。纯静态、浏览器本地计算，无运行时外部依赖。

## 计算器

- 框图工作区：元件库、网格画布、属性和端口预览。
- 输出端可拖线或点选连接输入端；支持分支、重接、选线删除、网格吸附、缩放平移、撤销和重做。
- 主信号链横向对齐，辅助源放在支路；“整理”重新排列，“全图”恢复随窗口自适应。手动缩放和平移后保留当前观察位置。
- 右键元件或连线可删除、断开连接、复制或继续分支；移动端可用元件右上角“⋯”。删除与断开均可撤销。
- 21种元件：信号源、表达式源、载波、噪声、常量、加法、乘法、增益、数学运算、相位延后、时间延时、积分、微分、Hilbert、包络、LPF、BPF、自定义H(f)、自定义h(t)、匹配滤波、输出。
- LPF设置截止；BPF设置中心与半带宽，也可直接改上下截止，两种设置保持一致。
- 匹配滤波有独立的接收输入、参考模板与采样时刻T；不把一般系统响应当作参考模板。
- 四个可编辑示例：DSB相干解调、AM相干解调、AM包络检波、矩形脉冲匹配滤波；可从空白开始。
- 表达式模式复用原AST计算引擎，支持多定义、依赖关系和数学键盘。无效草稿不会替换已生效图形。

图形包括时域、幅度谱、频点功率谱、有限窗PSD、可旋转三维复频谱、复平面。输入、已调、噪声、接收、系统处理与输出按含义分区。默认分栏并统一刻度，叠加比较需显式开启。每条曲线先显示含义，再显示符号。

“常用信号”默认关闭，打开后可查20种波形、脉冲和系统公式；支持复制、放入输入/系统/定义，或创建明确标为“期望输出”的参考对象。

## 概念辨析

29个单元按章节组织。每单元用关系图、参数实验与独立的推导阅读页解释一组易混概念。22篇推导包括条件、逐步计算、数值例子与结论。

流程卡片、正文行内记号、图例、坐标标签及推导公式使用本地KaTeX排版，字体随项目发布，无需外部CDN。复杂推导保留显式TeX源，独立HTML预先渲染，Markdown导出数学块。

波形图、概念关系图和端口小预览可点开放大；支持滚轮缩放、拖动平移和适应窗口。三维图可使用右上角放大按钮，原图拖动旋转保持可用。

## 本地预览与维护

```powershell
npm run dev
npm test
npm run build
```

打开 `http://127.0.0.1:4173/clab/`。模块和Worker需要HTTP访问；独立推导HTML可直接打开。`dist/`可部署到任意静态站点子目录。

后续维护源位于博客的 `clab/`：`D:\code\PersonalBlog\spartan-x125.github.io\clab`。`D:\code\Clab`为本轮工作副本。博客运行dev/build时自动从clab源码同步到public/clab，构建输出到docs/clab。本轮没有提交、推送或线上部署。

完整对象编辑器保留在 `workbench.html`，含原W1/W2/W3、39组表达式预设、场景保存与导出。它也显示可编辑信号含义与角色，默认单对象观察，勾选“叠加比较”才混合绘制。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| src/studio.js | 两个板块、计算事务、信号分区与概念页面 |
| src/block-editor.js | 画布交互、元件属性、端口预览、常用信号面板 |
| src/block-model.js | 框图校验、依赖排序与真正可计算的表达式 |
| src/graph-geometry.js | 缩放坐标、网格、布线与放置 |
| src/graph-actions.js | 删除元件、连线与断开连接的可撤销操作 |
| src/calculator-views.js | 六类视图、统一刻度、三维投影与PSD归一化 |
| src/signal-roles.js | 含义、符号、阶段与旧预设映射 |
| src/concepts.js / src/derivations.js | 单元关系与逐步推导内容源 |
| src/concept-labs.js / src/teaching-labs.js | 概念实验 |
| src/formula-tex.js / src/inline-tex.js / src/math-render.js | 显式推导TeX、短行内记号与统一数学排版 |
| src/plot-viewer.js | 单图放大、缩放与拖动查看 |
| src/engine.js / src/math.js / src/worker.js | 复用的AST、信号运算、FFT与独立计算线程 |

构建会重建分章Markdown、历史合订本与新的推导阅读文件。应编辑内容源，避免直接修改生成文件。

框图的空间组织与操作思路参考了《图灵完备》的搭建理念及[官方介绍](https://turingcomplete.game/)、[官方Steam展示](https://store.steampowered.com/app/1444480/Turing_Complete/)，未复制游戏代码或美术资源。
