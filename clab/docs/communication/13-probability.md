**理解主线：** 期望是线性加权平均，方差与协方差是二次量。先核对题干和随机变量支持集，再做代数。

## 13.1 期望线性，方差对系数平方

无需独立就有E[aX+bY+c]=aEX+bEY+c。方差则为a²DX+b²DY+2abCov(X,Y)。负号平方后不会让单个方差为负。

你提出过用D(Z₁+Z₂)反求Cov的路线，这是正确方法。若Z₁=2X+Y、Z₂=2X−Y，DX=DY=σ²且Cov(X,Y)=0，则两方差均5σ²，和为4X，Cov=(16−5−5)σ²/2=3σ²。

```text
Cov(Z₁,Z₂)=[D(Z₁+Z₂)−D(Z₁)−D(Z₂)]/2
Cov(aX,bY)=abCov(X,Y)
```

## 13.2 样本均值中同一个X₁不能当独立副本

独立同分布、方差σ²、Y=(1/n)ΣXᵢ时，DY=σ²/n，但Cov(X₁,Y)=σ²/n而不是0。故D(X₁−Y)=(n−1)σ²/n。

原验算11题EX=EY=1,DX=9,DY=1,ρ=−2/3，Cov=−2。X−2Y+3的均值2、方差21，所以二阶矩E[(X−2Y+3)²]=25。此题按原图重新计算，不能把方差当作二阶矩。

```text
E[Z²]=D(Z)+(EZ)²
Cov(X₁,X̄)=σ²/n
```

## 13.3 期望可以直接作用于函数

若X~Exp(1)，原S23题图可读为“又Y=X+e^{−2X}”，旧回答把“又”误读成了乘数X，导致错误地引入1/X并得到发散。正确EY=1+∫₀∞e^{−3x}dx=4/3。

S16图片：f(x;θ)=2x/(3θ²),θ<x<2θ。E[X²]=5θ²/2，所以E[cΣXᵢ²]=θ²给c=2/(5n)。这说明无需先求ΣXᵢ²的分布。

```text
E[g(X)]=∫g(x)f_X(x)dx
Exp(λ)：E[e^{−aX}]=λ/(λ+a)，a>−λ
```

## 13.5 不要把形式积分当作合法期望

标准Cauchy密度1/[π(1+x²)]的均值不存在。对称主值为0不等于通常意义下期望存在。若把密度读成1/[πx(1+x²)]，负半轴出现负值，就已经不是合法密度，不能先约掉x后宣称均值为1。

