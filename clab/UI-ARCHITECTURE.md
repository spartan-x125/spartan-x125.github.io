# Clab 界面与计算约定

## 两个板块

计算器承载自由定义、框图与结果；概念辨析承载关系图解和推导文章。图解/推导是单元内部切换，不再作为第三个主入口。历史合订本保留为资料。

默认只显示操作名称、变量、单位、必要的错误。长模型说明收进展开项，推导使用专门阅读排版，不挤在图形上方。

## 观察顺序

先选输入与系统，按信号链区分消息、载波、已调、噪声、接收、中间结果与输出，再选择视图。含义是主名称，符号是辅助标识，二者不互相代替。角色和名称可编辑，存储在对象上；修改符号不会丢失含义。

默认输入与输出分栏，同一种视图使用统一纵轴刻度，防止两个幅度不同的信号因为分别缩放而看起来一样大。噪声可单独观察；如需放大低幅细节，可关闭统一刻度。叠加比较是明确的操作，不是默认状态。

## 六类视图

| 视图 | 坐标与对象 | 定义 |
| --- | --- | --- |
| 时域 | t与当前信号的实部 | 不把系统频率响应画成时域波形；不同角色默认分栏 |
| 幅度谱 | f与复变换的模 | 数值连续变换乘Δt，界面显示\|X_T\|/T |
| 功率谱 | DFT频点与该频点的均方贡献 | P_k=\|X_T(f_k)\|²/T²，纵轴是权重；当前是有限记录分箱，不是无限长周期冲激的严格面积 |
| 功率谱密度 | f与每单位频宽的均方贡献 | S_T=\|X_T\|²/T，Δf=1/T，ΣS_TΔf=窗内均方值 |
| 三维谱 | f、Re X_T、Im X_T | 三个真实坐标经可旋转相机投影，拖动或方向键改变相机；可切换t、Re x、Im x的轨迹 |
| 复平面 | Re与Im | 等比例横纵坐标；默认对实输入构造有限记录解析信号，也可切回原实信号，其虚部应为0 |

计算器使用归一幅度及均方值，不擅自把积分/微分后的任意数学量解释为瓦特。具体物理量纲应跟随元件运算；教学文章中给出电阻为1Ω等条件时才按该模型使用V/W。复包络与真实带通的1/2不自动猜测，由用户的表示定义决定。

## 框图编辑

- 主路径按信号流横向对齐，第一输入与输出使用同一高度，载波和噪声等辅助输入放在下方。自动整理只改变位置，不改变参数和连线，且可撤销。
- 连线优先使用直角通道，绕开元件内部；复杂布局使用可见性网格寻路。缩放适配包含所有元件，窗口尺寸变化会重新适配；手动观察时保留视点。
- 右键菜单根据元件、连线或空白处提供操作；元件的“⋯”提供同一菜单。删除元件一并删除其相连线，其他元件保留并显示缺失输入，避免静默接错。删除、断线、复制、整理统一进入撤销历史。
- 元件库选择后在画布放置，也支持拖入。移动吸附20单位网格，端口位置与连线共享世界坐标。
- 空白拖动平移，滚轮或按钮缩放；缩放保持指针下的世界位置。全图按钮适配全部元件。
- 输出端拖到输入端，或点输出再点输入。同一输出可扇出到多个输入；每个输入只保留一个来源，重接可以撤销。
- 连线使用直角路径，选中后高亮，可删除或从来源继续分支。经过相同位置的线不自动成为连接点。
- 属性、端口预览、所选采样值与主波形都来自同一次引擎结果，不用伪造动画表示计算成功。
- 断线会使依赖它的下游失效；仍然完整的支路继续计算。循环在接线时拒绝，不假装已实现带状态的反馈仿真。
- 图模型按依赖编译成AST表达式，在Worker中计算。旧批次不能覆盖新状态。参数和表达式先校验，非法草稿保留错误信息及上一次有效值。

## 元件的明确含义

LPF按截止B生成rect(f/2B)。BPF按中心f₀与半带宽B生成rect((|f|−f₀)/2B)，上下截止为f₀±B；也可直接修改上下截止，反算中心与半带宽。BPF约束下截止非负。

H(f)系统走周期频域滤波；h(t)系统走有限窗口卷积，支持加权理想冲激。匹配滤波独立接入接收信号与参考模板，按h(t)=s*(T−t)计算，采样T不是自动猜出的峰值。

框图LPF/BPF采用周期FFT教学模型，非整周期边界可能振铃；表达式中的原Filter保持双倍补零行为。相位延后按正负频共轭恒相角实现，时间延时是x(t−τ)。积分从当前窗口起点累计且带初值，微分使用中心差分、端点单边差分；两者的误差和量纲在概念单元中讲清。

噪声是有限带宽采样模型，可设置标准差与种子，多个源可用不同种子。它不自动等同于理想连续白噪声或指定N₀。

## 常用信号

表格默认关闭。20个模板分成波形、脉冲、系统，提供纯公式复制、输入源、自定义系统、表达式定义与“期望输出”参考。期望输出不冒充当前框图的实际输出。

## 内容维护

29个概念单元对应22篇推导。每篇从适用条件开始，逐步说明等式变换的原因，并给出数值核对。原27个来源的历史整理保持独立，新增解释不冒称是原聊天逐字内容。

数学展示统一经本地KaTeX。复杂推导在formula-tex.js中逐条维护显式TeX，不靠猜测长Unicode公式的结构。流程卡片、标题中的符号、正文短记号、图例与坐标标签也进入数学渲染。SVG坐标标签通过foreignObject保留矢量图与HTML数学排版；纯数值刻度仍使用SVG文本。原始历史记录保留，不改写成聊天原文。

单图查看器复制当前图形快照，保持当前参数不变；支持居中缩放、拖动平移、方向键和复位。三维图拖动后不会误触放大；放大窗口查看当前投影，旋转仍在原图进行。流程图在手机放大窗口采用两列，避免整行公式过小。

当前画布是前向连续信号链仿真；旧完整对象编辑器继续提供符号序列、编码树、CRC、Viterbi等专门工具。不把这些结构结果强行混入连续信号的PSD或时域坐标。
