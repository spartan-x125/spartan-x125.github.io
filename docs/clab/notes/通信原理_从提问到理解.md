# 01 确定信号分析：从旋转到频谱

> “复平面乘 t”的空间坐标里，螺旋线如何变成以角速度除以 2π 为横轴的谱线？

**理解主线：** 傅里叶变换是逐个试探旋转频率、消除对应旋转，再把剩余向量沿时间积累。三维图帮助想象，真正完成变换的是乘法与积分。

## 1.1 先说清楚正在观察哪一个对象

确定信号的一条波形 x(t) 给定后，每个时刻的值已经确定。复指数 e^{j2πf₀t} 在复平面匀速旋转；把时间作为第三个轴，轨迹才成为螺旋线。实余弦不是一条单独旋转的复指数，而是正、反两个旋转分量的和。

频率 f 是每秒转数，角频率 ω=2πf 是每秒弧度。横轴以 Hz 标注时，变换核必须含 2π；把 ω 和 f 混用会直接改变谱线位置。

```text
A cos(2πf₀t+φ) = (A/2)e^{jφ}e^{j2πf₀t} + (A/2)e^{−jφ}e^{−j2πf₀t}
```

## 1.2 从你的螺旋线走到积分

在试探频率 f 的参考系中，先乘 e^{−j2πft}。原来频率 f₀ 的分量变成频率 f₀−f 的分量。当 f=f₀，它停止旋转，所有时刻指向同一方向，积分可以持续积累；不匹配时，各时刻的向量会部分抵消。

这不是普通三维坐标轴交换，也不是把一条螺旋线整体旋转成一根谱线。变换后的每一个频率点，都对应重新进行一次匹配与积分。一个频点同时保存大小和相位，单看幅度谱会丢失相位信息。

```text
X(f)=∫₋∞^∞ x(t)e^{−j2πft}dt
X_T(f)=∫₋T/2^T/2 x(t)e^{−j2πft}dt
```

## 1.3 为什么有限观察不是无限高的冲激

对于复指数，归一化的有限窗结果为 e^{jφ}sinc[(f₀−f)T]。T 越长，主瓣越窄；无限长复指数的傅里叶变换则是冲激，需要按广义函数解释，不能用普通函数的“在别处积分为零”草率替代。

图解采用对称观察窗和 X_T/T，因此同频复指数的峰值为1，余弦在正负频率各约为1/2。普通未归一化 X_T 的峰值随 T 增大。窗长、归一化和幅度单位必须同时写清。

```text
sinc(x)=sin(πx)/(πx)
ℱ{e^{j2πf₀t}}=δ(f−f₀)
ℱ{A cos(2πf₀t+φ)}=(A/2)e^{jφ}δ(f−f₀)+(A/2)e^{−jφ}δ(f+f₀)
```

## 1.4 能量、功率与谱线权重

有限能量信号用能量 E=∫|x(t)|²dt，Parseval 给出 E=∫|X(f)|²df。非零周期信号的总能量通常发散，应使用平均功率和傅里叶级数。

若周期信号的级数系数为 cₖ，则功率谱是 Σ|cₖ|²δ(f−kf₀)。余弦幅度谱的单根冲激权重为 A/2，功率谱的单根权重为 A²/4，两根合计功率 A²/2。不能把“幅度谱取平方”理解为计算 δ²。

```text
P=lim_{T→∞}(1/T)∫₋T/2^T/2 |x(t)|²dt
P_cos=A²/2
P_x(f)=Σₖ|cₖ|²δ(f−kf₀)
```

## 1.5 频移、翻转与共轭要分开

你提出过直接乘 exp(j2πWt) 来做频谱倒置。这能平移频谱，却不能对任意复频谱保证翻转关系；利用实信号的负频部分时，还必须跟踪共轭造成的相位变化。

若严格要求 M₂(f)=M₁(W−f)，可用 m₁(−t)e^{j2πWt}。但这个表达式一般为复信号；要求实输出时，必须再给出负频共轭镜像及滤波区间。实际通信中的实时实现还要考虑时间反转不具一般因果可实现性。

```text
x(t)e^{j2πWt} ↔ X(f−W)
x(−t) ↔ X(−f)
x*(t) ↔ X*(−f)
x(−t)e^{j2πWt} ↔ X(W−f)
```

# 02 系统、卷积与相关：同一种内积结构

> “把协方差和方差公式，还有能量的公式拆成积分形式对比看看。”

**理解主线：** 你发现的共同结构是“乘积的加权积累”。能量和方差都是自身内积，相关和协方差都是交叉内积；中心化与权重决定它们是否是同一个量。

## 2.1 LTI 为什么可以用卷积描述

将输入分解为各时刻冲激的加权叠加。线性允许分别响应后相加，时不变性让每个冲激只需要调用同一条 h(t) 的平移副本。系统输出于是是加权平移之和。

复指数是 LTI 的特征函数：同一频率输入经过系统后仍为同一频率，H(f) 只改变其复幅度。这把第1章的旋转图像与滤波联系起来。

```text
y(t)=x(t)*h(t)=∫ x(τ)h(t−τ)dτ
Y(f)=X(f)H(f)
e^{j2πft} → H(f)e^{j2πft}
```

## 2.2 滑动积分器其实是矩形窗

在5.10中，积分器前后相减可等效为一个长度 T 的滑动积分窗。由时域直接积分、冲激响应求导/叠加、频域积分器乘延时差，都可到达同一答案。

不要把积分上下限 t−T 到 t 读成 −T 到 T。前者随 t 滑动、窗长为 T；后者固定且长度为2T，得到的对象和系数均不同。

```text
y(t)=∫_{t−T}^t x(τ)dτ
h(t)=u(t)−u(t−T)
H(f)=T sinc(fT)e^{−jπfT}，H(0)=T
```

## 2.3 确定波形的归一化相关系数

对有限能量实信号 x,y，内积 ⟨x,y⟩=∫xy dt。将交叉内积除以各自长度，得到类似几何夹角余弦的相关系数。复信号需要共轭，归一化相关一般为复数，其模不超过1。

相关函数的时移符号在教材间可能不同。本册实信号采用 R_xy(τ)=∫x(t)y(t+τ)dt；使用复定义时可用 ∫x*(t)y(t+τ)dt。先固定定义，再比较公式。

```text
ρ_E=∫x(t)y(t)dt / √[∫x²(t)dt · ∫y²(t)dt]
|⟨x,y⟩|² ≤ ⟨x,x⟩⟨y,y⟩
```

## 2.4 概率论的相关系数多了一步中心化

对随机变量，内积的权重来自概率分布，而不必来自均匀时间。协方差先去掉均值，再计算交叉内积；方差就是中心化变量对自身的内积。

如果在长度 L 的观察区间上均匀抽取一个时间点 U，令 X=x(U),Y=y(U)，就能把时间积分转为期望。区间平均为零时，ρ_E 与 Pearson 系数一致；存在直流偏置时，它们通常不同。图解通过给第二条波形加偏置展示这个反例。

```text
E[X]=∫x f_X(x)dx
Cov(X,Y)=E[(X−EX)(Y−EY)]
ρ_P=Cov(X,Y)/√[D(X)D(Y)]
E[x(U)y(U)]=(1/L)∫区间 x(t)y(t)dt
```

## 2.5 取等、不相关与独立分别回答什么

柯西–施瓦茨取等表示两个对象线性相关：波形空间中 y=kx（几乎处处），随机变量空间中中心化后 Y−EY=k(X−EX)（几乎必然）。它不是“独立”的条件。

3.8的白高斯噪声经两个模板积分后构成联合高斯变量。此时零协方差才可以推出独立；方差分别由模板能量确定，交叉协方差由模板内积确定。不要把联合高斯条件省掉。

```text
ξᵢ=∫₀^T n(t)φᵢ(t)dt
Cov(ξ₁,ξ₂)=(N₀/2)∫₀^T φ₁(t)φ₂(t)dt
联合高斯且 ∫φ₁φ₂dt=0 ⇒ ξ₁,ξ₂ 独立
```

# 03 解析信号、复包络与低通等效

> 信号和复包络图像上有什么联系？输出复包络为什么不能直接卷积系统的复包络，还要乘 1/2？

**理解主线：** “去掉负频率”“搬移到基带”“取实部”是三个不同操作。滤波器冲激响应的复包络与系统等效低通响应也不是同一个定义。

## 3.1 希尔伯特变换不是任意把 cos 改成 sin

采用 H_H(f)=−j sgn(f)：正频移相−π/2，负频移相+π/2，所以 H{cos(2πf₀t)}=sin(2πf₀t)，H{sin}=−cos。

对一般幅相变化信号，必须检查频谱条件。窄带包络与载波频带分离时可以用 Bedrosian 型结论；只因表达式写成 cos[θ(t)]，不能对任意 θ(t) 宣称其希尔伯特变换精确等于 sin[θ(t)]。非线性调相可能产生宽频谱。

```text
x_a(t)=x(t)+j x̂(t)
X_a(f)=2X(f)，f>0；X_a(f)=0，f<0
直流分量保持原系数，不翻倍
```

## 3.2 从实带通到解析，再从解析到包络

解析信号 x_a 还在原来的正频带上，复包络 x_L=x_a e^{−j2πf_ct} 才搬到基带。复包络可以含有负频率：它表示相对载频向下的偏移，并不违反解析信号只有正频率。

采用北邮常用非能量归一化约定，x_L=I+jQ，则实带通 x=I cos(2πf_ct)−Q sin(2πf_ct)。解析信号、复包络、幅度包络 |x_L| 不能互换名称。

```text
x_L(t)=x_a(t)e^{−j2πf_ct}
x(t)=Re{x_L(t)e^{j2πf_ct}}
幅度包络 A(t)=|x_L(t)|；相位偏移 φ(t)=arg x_L(t)
```

## 3.3 相干解调是选观察方向

将带通信号乘 2cos(2πf_ct+θ) 并理想低通，得到 I cosθ+Q sinθ。θ=0时恰好得到I，所以“同相分量有用”由当前调制与本振相位决定。

SSB中Q通常是I的希尔伯特伙伴，仍含消息信息；QPSK中I与Q各承载信息。不能把正交分量统一视作噪声。对USB约定 x=m cos−m̂ sin，则I=m,Q=m̂。I−H{Q}=2m（无直流条件），缩放后可用两路合成恢复消息。

```text
2 LPF{x(t)cos(2πf_ct+θ)}=Re{x_L(t)e^{−jθ}}
=I(t)cosθ+Q(t)sinθ
```

## 3.4 为什么卷积前多出 1/2

将冲激响应 h 的复包络记为 h_L，它的低通频谱为 H_L(f)=2H(f+f_c)。而系统等效低通传递函数 H_eq(f)=H(f+f_c)，因此 h_eq=h_L/2。

输出与输入复包络的关系是 Y_L=X_L H_eq=(1/2)X_L H_L。因子来自“取实部时正负频各分到一半”和“构造解析信号时正频翻倍”的配套定义。不能通过更换符号把同一物理系统变成两倍增益。

```text
h_eq(t)=h_L(t)/2
y_L=x_L*h_eq=(1/2)x_L*h_L
H_L(f)=2H(f+f_c)，H_eq(f)=H(f+f_c)
```

## 3.5 用原来的2.6做一个系数检查

原题可读到：x(t)=cos(2πf_ct) 在0<t<T内非零，h(t)=2cos(2πf_ct) 在同一区间非零，且f_c=4/T。按题目的窄带低通等效模型，x_L=1、h_L=2、h_eq=1（均为长度T的窗），所以 y_L 是两个单位矩形窗的卷积，峰值 T。

直接 x_L*h_L 的峰值会变成2T；这正是你追问的差别。图解把三条低通结果同时画出。矩形截断带通脉冲并不严格带限，精确物理卷积还可能有高频边缘项；低通等效图不冒充有限载频下全部瞬时细节。

```text
y_L(t)=t，0≤t≤T；y_L(t)=2T−t，T≤t≤2T；其他为0
```

## 3.6 能量与功率为什么也有 1/2

当带通两侧频带不重叠、没有直流等特殊成分时，实带通能量是其解析信号或本约定复包络能量的一半。复包络移频不改变能量。

有些教材采用 √2 或2的不同缩放，公式会一起变化。判定是否正确应从 x=Re{x_L e^{jω_ct}} 的定义出发，而不是单独背“低通等效总有二分之一”。

```text
E_x=(1/2)∫|x_L(t)|²dt
P_x=(1/2)E[|x_L(t)|²]
```

# 04 随机过程：期望沿着哪一个轴计算

> 期望不是对 x f(x) 积分吗？为什么含随机相位的均值可以对 φ 积分，却不需要再对 t 积分？

**理解主线：** 固定 t 后跨样本取平均，是集合平均；固定样本后跨 t 取平均，是时间平均。积分写在哪个变量上，取决于随机性来自哪里。

## 4.1 一个过程是许多条样本函数

写成 X(t,ω) 时，t 是时间坐标，ω 标识抽到的样本。固定ω得到一条波形，固定t得到一个随机变量。E[X(t)] 是在同一时刻对样本集合加权平均。

若 X(t)=g(t,Φ)，Φ有密度 f_Φ，直接对Φ积分就是随机变量函数的期望公式，不需要先求 X(t) 的概率密度。这里t是暂时固定的参数。

```text
m_X(t)=E[g(t,Φ)]=∫g(t,φ)f_Φ(φ)dφ
时间平均：lim_{T→∞}(1/T)∫₋T/2^T/2 X(t,ω)dt
```

## 4.2 把3.3随机相位余弦从积分算起

令Y(t)=X(t)cos(2πf_ct+Φ)，其中Φ与X过程独立且均匀分布于[−φ₀,φ₀]。均值不是“对时间积分”，而是固定t后对Φ积分。若 X 的均值为m_X，则 m_Y(t)=m_X cos(2πf_ct)sinφ₀/φ₀。

互相关里的两个余弦相乘后，用积化和差产生两项：一项只依赖τ，另一项还依赖2t+τ。第二项的系数 sin(2φ₀)/(2φ₀) 决定它是否消失。不能把两项全部省去，也不能仅由相位“随机”就断言平稳。

```text
E_Φ[cos(ω_ct+Φ)]=(1/2φ₀)∫₋φ₀^φ₀ cos(ω_ct+φ)dφ
=cos(ω_ct)sinφ₀/φ₀
R_Y(t,τ)=(R_X(τ)/2){cos(ω_cτ)+[sin(2φ₀)/(2φ₀)]cos[ω_c(2t+τ)]}
```

## 4.3 广义平稳必须同时检查均值与相关

广义平稳要求均值常数、二阶矩有限、相关仅依赖时差。若X为零均值平稳过程，只需让上式的t项消失；在原题0≤φ₀<π内，非退化解φ₀=π/2。若m_X≠0，φ₀=π/2时均值仍随t变，不能再宣称平稳。

图解用幅度固定的余弦展示集合平均和相关。相位遍历完整2π时，均值为零、相关只依赖τ；较窄相位区间可能出现二阶相关不依赖t，但均值仍变化的反例。Φ固定时还要按退化确定过程处理。

```text
广义平稳：m_X(t)=常数，R_X(t,τ)=R_X(τ)
R_X(0)=E[X²(t)]；D[X(t)]=R_X(0)−m_X²
```

## 4.4 不相关不等于独立

Cov(X,Y)=0只说明没有线性相关，不能排除非线性依赖。原题 X~U(0,2),Y=X³ 中：EX=1,EY=2,E[XY]=16/5，所以Cov=6/5>0；Y还是X的确定函数，当然不独立。

需要一个“不相关但不独立”的例子时，可另取X~U(−1,1),Y=X²；这不是原题的答案，而是本次补充的反例。EX=E[X³]=0，Cov=0，但知道X就知道Y。联合高斯是零协方差推出独立的重要特例。

```text
Cov(X,Y)=E[XY]−EX·EY
联合高斯且 Cov=0 ⇒ 独立
仅各自边缘为高斯，不足以替代“联合高斯”
```

## 4.5 白、高斯、平稳与遍历是不同属性

白性描述不同时刻的二阶相关或频谱平坦，高斯性描述有限维联合分布，平稳性描述分布或统计量在时间平移下不变，遍历性描述时间平均能否替代集合平均。它们不能互相代称。

对WSS输入经过稳定LTI系统，均值乘直流增益、功率谱乘|H|²。高斯过程经线性系统仍高斯，但有色化以后通常不再白。理想连续白噪声不宜当作每点可直接取值且有限方差的普通波形。

```text
m_Y=m_X H(0)
P_Y(f)=|H(f)|²P_X(f)
P_n(f)=N₀/2 ↔ R_n(τ)=(N₀/2)δ(τ)
```

来源：S09、S10、S16、S17、S18、S26。

# 05 模拟调制：频谱搬移与载波参数

> 为什么叫幅度调制？它不是改变中心频率和频率分布更多吗？SSB为什么不能只做频谱搬移后截取？

**理解主线：** 调制名称按信息写进载波的哪个参数来命名；频谱搬移描述乘法的结果。时域参数与频域分布是同一信号的两种观察方式。

## 5.1 AM与FM回答的是不同的问题

AM以A(t)承载消息，FM以瞬时频率承载消息，PM以相位偏移承载消息。出现新的边带，不等于发生了FM。

对常规AM且无过调制、包络不穿零时，正包络为A_c[1+μm_n(t)]，载波相位仍为2πf_ct。对DSB的负幅度段若强制采用正幅度表示，会引入π相位跳变；不应把这些表示细节误当成FM。

```text
AM：s=A_c[1+μm_n(t)]cos(2πf_ct)
FM：s=A_c cos[2πf_ct+2πk_f∫m(τ)dτ]，f_i=f_c+k_fm(t)
PM：s=A_c cos[2πf_ct+k_pm(t)]，f_i=f_c+(k_p/2π)m′(t)
```

## 5.2 你的“搬移再截取”方法成立

m(t)乘cos载波会生成两个幅度各为1/2的频移副本。SSB滤波法就是在DSB后选择一组边带；对实输出，必须同时保留相应的负频共轭镜像。

下边带是靠近零频的那一对：正频f_c−f_m和负频−f_c+f_m；不能在正负两侧机械地都选择坐标更小的一根。已给定DSB增益再滤去一半，与标准幅度归一化的SSB公式可能相差2，要先核对调制器系数。

```text
m(t)cos(2πf_ct) ↔ [M(f−f_c)+M(f+f_c)]/2
USB=m cos(2πf_ct)−m̂ sin(2πf_ct)
LSB=m cos(2πf_ct)+m̂ sin(2πf_ct)
```

## 5.3 带宽到底数了哪两侧

实带通信号在正频带[f_c−W,f_c+W]占宽2W，这里的“两侧”是载波两侧的上下边带。负频带是实信号的共轭镜像，不再把通信带宽翻倍为4W。

DSB或普通AM消息带宽W时，正频带宽2W；SSB为W。理想低通的截止B则通过[−B,B]，积分噪声时总长度是2B。两种“两侧”含义不同。

```text
B_DSB=2W；B_SSB=W
B_lowpass=正频截止；双边积分区间长度=2B_lowpass
```

## 5.4 边带功率从表达式算，防止归一化重复

设m(t)=μm_n(t)，其中m_n峰值归一化，则P_m=μ²P_mn。零均值、频带分离的常规AM有P_c=A_c²/2，P_SB=(A_c²/2)P_m。若已经给出P_m，就不能再乘一次μ²。

单音m_n=cos时P_mn=1/2。你之前的4.6中s=cos(1600πt)+4cos(2000πt)+cos(2400πt)=4[1+0.5cos(400πt)]cos(2000πt)，载波功率8，双边带功率1，总功率9，效率1/9。各余弦的平方平均不能当作1。

```text
P_SB=(A_c²/2)μ²P_mn=(A_c²/2)P_m
η=P_SB/(P_c+P_SB)=P_m/(1+P_m)
单音：η=μ²/(2+μ²)
```

## 5.5 相干解调、相位误差与同步

相干接收需要匹配载频和相位，取2cos本振可抵消混频固有的1/2。DSB的相位误差使输出为m cosθ；SSB则出现m与m̂的混合，通常不能仅看一个cosθ幅度衰减。

抑制载波SSB一般无法无条件从任意未知消息中恢复唯一载波。插入导频并提取导频/锁相是原会话讨论的方案，但它需要发射端结构配合，不能把“任何SSB都可直接用普通载波PLL恢复”写成通用规则。

```text
DSB同步：2LPF{m cosω_ct · cosω_ct}=m
USB相差θ：m cosθ+m̂ sinθ
```

来源：S03、S05、S06、S07、S26。

# 06 噪声系数：从功率谱面积重新计算

> “我经常在相干解调噪声的最后答案出现系数问题……什么时候 N₀B 的系数怎么变化？”

**理解主线：** 噪声功率永远是输出PSD的积分。N₀B只是特定谱高、频带和增益组合下的面积，不是跨越混频器仍保持不变的标签。

## 6.1 先写谱高，再写区间

约定输入实白噪声双边谱N₀/2，单边谱为N₀。单位增益低通通过[−B,B]，输出功率(N₀/2)×2B=N₀B。单位实带通在正频保留宽B_RF并有负频镜像，功率同样为N₀B_RF。

同一个字母B若一会儿表示低通截止、一会儿表示双边总长，系数就会错。每次都把积分区间写出来。非矩形滤波器应用|H|²积分或等效噪声带宽。

```text
N_o=∫ P_in(f)|H(f)|²df
理想低通：N_o=∫₋B^B N₀/2 df=N₀B
```

## 6.2 混频器把噪声的哪些频段叠起来

噪声乘k cos(2πf_ct)后，时间平均PSD为(k²/4)[P_n(f−f_c)+P_n(f+f_c)]。这是WSS输入周期调制后的时间平均谱表述。低通将移到基带的部分留下。

DSB前置滤波器保留载波两侧各宽B；搬到基带后，两份噪声在[−B,B]重叠，谱高k²N₀/4，积分为k²N₀B/2。若只有SSB所需的单侧边带及镜像，两份搬移噪声各占基带半区，谱高k²N₀/8，总功率k²N₀B/4。

```text
DSB：N_o=(k²/2)N₀B
SSB：N_o=(k²/4)N₀B
取k=2：DSB为2N₀B，SSB为N₀B
```

## 6.3 为什么同一消息带宽下DSB与SSB会有不同系数

上面的差别同时指定了前置带通滤波器、消息带宽和混频器增益。若SSB信号却仍使用宽DSB的前置滤波器，额外噪声没有被提前滤掉，就不能套窄SSB的N₀B结果。

某些系统用cos而不是2cos，信号和噪声功率都会一起缩小4倍，输出SNR不因这种纯增益改变。单独把噪声除以4却沿用原信号功率，会制造虚假的SNR提升。

```text
本振幅度×k ⇒ 恢复信号幅度×k，噪声标准差×|k|
SNR=(k²S)/(k²N)=S/N
```

## 6.4 窄带噪声I/Q与“有用信号”

窄带噪声写为n_c cosω_ct−n_s sinω_ct。本振相位零时只读出n_c；这里n_c仍然是噪声。只有加上信号以后，才分别讨论有用I与噪声I。

对围绕载频对称的实带通白噪声，两正交分量有相同功率。同一时刻不相关并不自动意味着两个完整过程独立；若带通谱关于载频不对称，跨时延交叉相关需要另外计算。

```text
n(t)=Re{[n_c(t)+jn_s(t)]e^{jω_ct}}
P_n=(1/2)(P_nc+P_ns)
```

## 6.5 做题时可复用的系数核对顺序

先画输入双边PSD与滤波器；再把每一个频带搬移到基带；对每条搬移路径乘幅度系数的平方；最后只对实际留下的频率区间积分。信号沿同一条链路计算。

4.40中300～3400Hz的语音频带只是单侧宽3100Hz，负频镜像及前置滤波器结构仍会影响PSD面积。题干不完整时不能仅由3100直接决定最终系数。

- 谱高：N₀还是N₀/2？
- 带宽：低通截止、正频带宽，还是双边总长？
- 前置选择：DSB两边带还是SSB单边带？
- 本振：cos、2cos，或另有增益？
- 结果：功率单位W，谱密度单位W/Hz。

来源：S03、S05、S09、S26。

证据说明：N₀B系数、4.22带宽、同相噪声问题可读；采用统一双边谱重新推导。

# 07 PAM功率谱：离散时钟如何进入连续频域

> 为什么没有对 R_a(m) 做傅里叶变换？为什么 g(t−nTₛ) 的时移指数，恰好提供了 R_a 的 DTFT 核？

**理解主线：** 这不是巧合。离散码元在等间隔时刻激励脉冲，连续时间的时移相位自然携带着离散序列的频率信息。脉冲谱与序列统计由这一结构接起来。

## 7.1 模型与平稳性边界

令aₙ为离散时间WSS实序列，均值m_a、方差σ_a²，R_a[k]=E[aₙaₙ₊ₖ]。连续PAM是每个aₙ对g(t)副本的加权和。

固定时钟PAM一般是循环平稳而非普通WSS，因此本章计算时间平均相关及其傅里叶变换。随机化时钟原点也可以构造平稳化模型，但要写明新引入的随机变量。

```text
s(t)=Σₙaₙg(t−nTₛ)
R_a[k]=C_a[k]+m_a²
R̄_s(τ)=(1/Tₛ)∫₀^Tₛ E[s(t)s(t+τ)]dt
```

## 7.2 先把求和变成一个看得见的卷积

设R_g(τ)=∫g(u)g(u+τ)du。对相关函数的双重求和按码元间距k分组，并对一个码元周期平均，可以得到脉冲自相关的等间隔加权平移。

把R_a[k]嵌入冲激列r_a(τ)=ΣR_a[k]δ(τ−kTₛ)，这就是熟悉的连续时间卷积。这里R_a不是被当成τ的连续函数直接变换，而是通过冲激列嵌入连续时间。

```text
R̄_s(τ)=(1/Tₛ)ΣₖR_a[k]R_g(τ−kTₛ)
=(1/Tₛ)R_g(τ)*ΣₖR_a[k]δ(τ−kTₛ)
```

## 7.3 时移指数正是序列的频率坐标

对每个平移的R_g做FT会生成e^{−j2πfkTₛ}，而同一个k正是R_a的离散时差索引。把全部项相加便是R_a的DTFT。没有遗漏一次变换，也不是g的FT“碰巧”替R_a做了运算。

离散角频率Ω=2πfTₛ。DTFT每2π周期，因此序列频谱在连续f轴上每1/Tₛ周期；最终PAM谱再由|G(f)|²塑形，一般不再整体周期。

```text
P_s(f)=(|G(f)|²/Tₛ)ΣₖR_a[k]e^{−j2πfkTₛ}
=(|G(f)|²/Tₛ)S_a(e^{jΩ})，Ω=2πfTₛ
```

## 7.4 不相关时为什么还有m_a²

不同码元不相关意味着协方差为零，而不是乘积期望为零。所以C_a[k]=σ_a²δ[k]，R_a[k]=σ_a²δ[k]+m_a²。

均值项在所有k上都存在，其DTFT是周期冲激列。一个1/Tₛ来自时间平均，另一个1/Tₛ来自冲激列的尺度变换，离散谱因此有1/Tₛ²。

```text
Σₖe^{−j2πfkTₛ}=(1/Tₛ)Σₗδ(f−l/Tₛ)
P_s(f)=(σ_a²/Tₛ)|G(f)|²
  +(m_a²/Tₛ²)Σₗ|G(l/Tₛ)|²δ(f−l/Tₛ)
```

## 7.5 均值是周期骨架，方差是随机波动

将aₙ=m_a+bₙ，则s=m_aΣg(t−nTₛ)+Σbₙg(t−nTₛ)。前一项是确定周期骨架，后一项是零均值随机波动；互不相关码元时，随机部分的谱为连续曲线。

m_a=0消掉的是“均值产生的谱线”，不保证任何相关序列都无线谱。若bₙ有长期周期相关，协方差谱本身也可能含线谱。图解仅对应不相关码元，明确把连续PSD与冲激权重分成两幅图。

```text
s_mean(t)=m_aΣₙg(t−nTₛ)
s_random(t)=Σₙ(aₙ−m_a)g(t−nTₛ)
```

## 7.6 全占空矩形为什么只剩直流谱线

g为长度Tₛ的单位矩形，则G=Tₛsinc(fTₛ)e^{−jπfTₛ}，非零整数l处G(l/Tₛ)=0，时钟谐波被脉冲谱零点消掉，只剩直流m_a²δ(f)。

改成占空比d<1的归零矩形，宽度dTₛ，非零时钟谱线一般会重新出现。图中改变m_a、σ_a²、Tₛ和d，分别观察线谱权重、连续谱、时钟间隔与零点的位置。

```text
d=1：P_s=σ_a²Tₛsinc²(fTₛ)+m_a²δ(f)
∫P_s(f)df=σ_a²+m_a²
宽度dTₛ：平均总功率=d(σ_a²+m_a²)
```

来源：S01、S02、S26。

证据说明：PAM推导、Ra的DTFT为何藏在时移指数中等连续追问可读；谱线问题按实际提问而非会话标题归档。

# 08 数字基带：重叠不等于码间干扰

> 数字基带传输最终怎样读回码元？为什么几条脉冲明明叠在一起，仍然可以无串扰？

**理解主线：** 无ISI约束的是每个判决时刻的贡献，不是要求整段时间中每个脉冲互不重叠。必须看完整发送—信道—接收的总响应。

## 8.1 把完整链路缩成总脉冲

设发送滤波G_T、信道C、接收滤波G_R，总响应H=G_T C G_R，逆变换为p(t)。接收采样值是目标脉冲贡献、其他码元贡献与噪声的和。

因此调制后的连续波形、接收滤波后连续输出、判决前采样值、最终离散比特，是四种不同对象。要逐个节点标注。

```text
y(kTₛ)=aₖp(0)+Σₙ≠ₖaₙp[(k−n)Tₛ]+Nₖ
正确归一化下：p(0)=1，p(kTₛ)=0（k≠0）
```

## 8.2 时域零点与频域平铺是同一条件

在变换和求和条件成立时，p(kTₛ)=δ[k]等价于频谱每1/Tₛ平移后求和为常数Tₛ。它允许频域副本互补，而不是要求每个副本完全不重叠。

带限实低通最小单侧带宽1/(2Tₛ)。这个符号率界与采样定理的形式相似，但一个约束无码间干扰传输，一个约束一般带限波形重建，不能把“接收机每码元采一次样”直接当成对全部波形做无损重建。

```text
ΣₘP(f−m/Tₛ)=Tₛ
B_min=R_s/2，R_s=1/Tₛ
```

## 8.3 升余弦留出了多少余量

总升余弦响应p(t)=sinc(t/Tₛ)cos(παt/Tₛ)/[1−(2αt/Tₛ)²]，α∈[0,1]。在可移除奇点处应使用极限，不能画成无穷高尖峰。

单侧截止B=(1+α)/(2Tₛ)。α增大增加带宽，通常使远处脉冲尾部衰减更快；正确采样时刻仍保持零ISI。图解将每个码元脉冲、合成波形、目标抽样贡献与ISI分开。

```text
p(0)=1
p(±Tₛ/(2α))=(π/4)sinc[1/(2α)]
B=(1+α)R_s/2
```

## 8.4 RC、RRC、匹配与无ISI不是同一要求

RC在这里指整条链路总响应。常用方案是发送和接收各一只相配RRC，在平坦信道下级联形成RC；单只RRC本身并不满足RC的采样零点条件。

匹配接收要求最大采样SNR，无ISI要求其他码元在采样点的贡献为零。两个目标不同，良好设计可兼顾，但不能从“匹配”一个词直接推出“无ISI”。

```text
G_total=G_T C G_R
平坦信道且G_R匹配G_T：|G_T|²取RC谱 ⇒ 总响应为RC
```

## 8.5 定时偏差、眼图与均衡

采样偏差ε时，邻居脉冲在(k−n)Tₛ+ε处不再保证为零；即使σ=0也可能产生ISI。眼图将多个码元区间折叠，在同一采样相位比较幅度分布与过零。

眼高受噪声、ISI、增益等共同影响，眼宽与时序容忍度相关。先固定噪声只改定时，再固定定时只改噪声，有助于区分原因。均衡试图补偿总响应失真；零迫可能放大深衰落处噪声。

```text
y(kTₛ+ε)=aₖp(ε)+Σₙ≠ₖaₙp[(k−n)Tₛ+ε]+Nₖ
```

## 8.6 符号率、信息比特率和带宽

M进制每符号通常承载log₂M个标记比特。无编码时R_b=R_s log₂M；若编码率R_c，信息率R_info=R_c R_s log₂M。滚降带宽约束的是符号率，不能直接把信息率代入。

线路码型还要看其序列相关性与脉冲波形；“零均值”“有无直流”“是否有时钟线”要由第7章PAM模型分别判断，不能只看0和1外观。

```text
R_info=R_cR_slog₂M
实基带：B=(1+α)R_s/2
对应I/Q带通：B_RF=(1+α)R_s
```

来源：S01、S02、S24、S25、S26。

证据说明：数字基带会话、Clab原始需求及此前复习源稿；“重叠与采样”作为这些记录的连接性补充展开。

# 09 匹配滤波与判决：投影后的概率面积

> “将高斯噪声谱在时域上左右搬移……再判断大于或小于零那一小部分面积？”

**理解主线：** 保留你“左右平移再看面积”的几何直觉，但横轴应是判决统计量的取值。平移由发送信号决定，先验概率改变加权和最佳门限。

## 9.1 接收机要把一段波形变成什么

发送反极性波形±v(t)，收到r(t)=±v(t)+n(t)。相关器将整段波形与模板g(t)相乘积累，输出一个数Y。抽样读取处理后的统计量，判决才把这个数映射成0或1。

所以接收目标未必是恢复一条绝对干净的波形，而是让不同发送假设在接收机的观察方向上尽量可区分。

```text
Y=∫₀^T r(t)g(t)dt=±C+N
C=∫₀^T v(t)g(t)dt
σ_N²=(N₀/2)∫₀^T g²(t)dt
```

## 9.2 匹配滤波器最大化什么

在实AWGN双边谱N₀/2下，C²/σ_N²=[(∫vg)²]/[(N₀/2)∫g²]≤2E_v/N₀。取g=kv时达到上界。

相关器模板g=v；等效滤波器冲激响应要时间反转并按复数情形共轭，即h(t)=kv*(T−t)。二者在t=T产生相同内积，却不是同一条时域函数。匹配滤波并非保证噪声绝对变小，而是最大化信号采样值相对于噪声宽度的可分性。

```text
h(t)=kv*(T−t)
y(T)=k∫r(τ)v*(τ)dτ
最大采样SNR=2E_v/N₀
```

## 9.3 两条高斯平移了什么

若C>0、N~N(0,σ²)，则Y|+~N(C,σ²)，Y|−~N(−C,σ²)。横轴y是随机变量的可能取值；纵轴是概率密度，面积才是概率，不是噪声PSD或时域波形。

门限γ：Y>γ判正，否则判负。发送正时错误是右边密度落到γ左侧的尾部；发送负时错误是左边密度落到γ右侧的尾部。这两块面积各自条件不同，必须由先验概率加权后才得到总错误率。

```text
P(−|+)=Q[(C−γ)/σ]
P(+|−)=Q[(C+γ)/σ]
P_e=p₊Q[(C−γ)/σ]+(1−p₊)Q[(C+γ)/σ]
```

## 9.4 先验不搬动条件密度，却会搬动最佳门限

等先验、等方差、同误判代价时γ=0最优，P_e=Q(C/σ)。非等先验时，MAP比较p₊f(y|+)与p₋f(y|−)，最佳门限向较少发送的信号一侧移动，扩大常见信号的判决区。

当p₊更大，γ_MAP变为负值，但两条条件密度的中心仍然±C。图解同时显示原始条件密度和两种错误尾部，并提供“采用MAP门限”。

```text
γ_MAP=(σ²/2C)ln[(1−p₊)/p₊]，C>0
等先验：γ=0，P_e=Q(C/σ)
```

## 9.5 模板正交时为什么像猜硬币

若∫vg=0，则C=0，两个假设下的统计量分布完全重合。等先验时任何基于这个Y的判决都不能优于1/2；固定过零判决也恰为1/2。

先验不等时，最优办法是总选更常见的假设，最小错误率为min(p₊,p₋)，不应继续笼统写“完全不可分就一定1/2”。若C<0却坚持Y>0判正，条件概率会反过来，误码可能超过1/2；翻转判决方向即可恢复正确的语义。

```text
C=0：f(y|+)=f(y|−)
等先验 P_e=1/2
一般先验 P_e,min=min(p₊,1−p₊)
```

## 9.6 你的图像还可以接到信号空间

把v/√E_v当成一个单位方向，模板与它夹角θ。单位能量模板投影得到C=√E_v cosθ，噪声标准差仍为√(N₀/2)，两高斯中心距离随cosθ缩小。

整体放大模板会同时放大C和σ，C/σ保持不变；转动模板改变方向，才会改变分离度。这里二维向量是波形空间的教学截面，不是把任意波形都限制为两个采样点。

```text
g单位能量时：C/σ=√(2E_v/N₀)cosθ
模板增益k≠0：|C|/σ保持不变
```

证据说明：匹配滤波、5.9/5.10/5.11、左右平移高斯的连续讨论可读；3.8原题用于连接噪声投影。

# 10 数字频带：从星座距离到可靠性

> 此前复习与Clab开发已经涉及数字频带传输，需要把它接到“复包络投影—噪声—判决”的主线。

**理解主线：** 星座是波形在正交归一基下的坐标。等概AWGN下的可靠性由距离相对于每维噪声宽度决定，不由图上看起来的绝对大小决定。

## 10.1 信号空间与最小距离

正交归一基φᵢ满足∫φᵢφⱼ*=δᵢⱼ。将波形投影得到坐标s_mi，AWGN在每个实单位基上的投影方差N₀/2。等概ML选择最近星座点，非等概MAP还要计入先验。

二元等概错误率可由波形距离d²=∫|s₁−s₀|²dt统一表示。反极性BPSK在同一平均比特能量下距离更大，相干OOK和正交2FSK的距离较小。

```text
P_b=Q[√(d²/(2N₀))]
MAP：选择最小 ||r−s_m||²−N₀ln p_m
```

## 10.2 BPSK与QPSK的两个能量口径

BPSK的P_b=Q(√(2E_b/N₀))。Gray QPSK在理想同步AWGN下由两条正交BPSK组成，P_b相同；每符号2 bit，因此E_s=2E_b，P_s=2P_b−P_b²。

不能把QPSK的符号错误率当作比特错误率，也不能把E_s/N₀直接代入E_b/N₀位置。固定E_s与固定E_b是两种比较条件。现有工作台“星座与接收”提供BPSK/QPSK、相位偏差与符号噪声。

```text
无编码：E_s=E_b log₂M
QPSK：P_b=Q(√(2E_b/N₀))，P_s=2P_b−P_b²
```

## 10.3 多进制带来什么代价

M增大每符号标记比特数提高，可在给定符号率下提高比特率；但平均能量相同时星座更密，对噪声和同步更敏感。

对方形M-QAM，可用一维PAM判决推广得到精确SER；Gray BER≈SER/log₂M只在高SNR、主要最近邻错误时适用。一般M-PSK近似也需标记高SNR及M范围，不能给出无条件的等号。

```text
方形M-QAM：P_s=1−{1−2(1−1/√M)Q[√(3E_s/((M−1)N₀))]}²
对称M-PAM：P_s=2(1−1/M)Q[√(6E_s/((M²−1)N₀))]
```

## 10.4 差分编码与差分检测的边界

相干BPSK先硬判决再差分译码时，在相邻硬判错误独立的模型下，信息比特错误率2p(1−p)。相邻符号直接延迟相乘的DPSK差分检测则是另一种接收结构，不能沿用这个公式。

相干正交2FSK与非相干能量检测也对应不同的噪声统计和错误率。必须把调制、编码、检测结构一起命名。

```text
DPSK理想差分检测：P_b=(1/2)e^{−E_b/N₀}
相干硬判后差分译码：P_b=2p(1−p)
```

证据说明：来自此前复习文稿和已实现Clab场景；没有将这些综述伪称为本次读取到的逐题原创点子。

# 11 已有复习内容：采样、信息、信道与编码

> 既有资料整理已经涵盖这些内容；本章保留核心关系和适用条件，作为主线之外的查询入口。

**理解主线：** 表示变换、信息压缩和增加抗错冗余各解决不同问题。计算链路时应让每一级的速率、能量、带宽与开销对应起来。

## 11.1 采样、混叠与重建

实低通信号最高频率W，通常取f_s>2W，满足相应边界条件时2W可作为理论奈奎斯特率。采样在频域复制原谱；混叠后不同原信号产生相同采样值，单纯提高插值精度不能恢复已丢失的区分。

现有W1“采样与混叠”支持教学采样率和有限sinc重建。内部绘图点数不是物理采样率；有限重建有边缘截断，不能冒充无限理想求和。

```text
M_s(f)=f_sΣₖM(f−kf_s)
m(t)=Σₙm(nT)sinc[(t−nT)/T]
```

## 11.2 PCM、量化与TDM

PCM为采样—量化—编码。b bit/样值、L=2ᵇ级时R_b=bf_s。均匀量化Δ=2A/L，无过载且误差近似均匀时N_q≈Δ²/12；满幅正弦高分辨率SQNR≈6.02b+1.76 dB，并非所有输入都成立。

非均匀量化失真要对每个分区积分。Lloyd–Max必要条件是重建值为条件均值，阈值为相邻重建值中点；迭代驻点不等于自动达到全局最优。A律教学8位码是1位极性+3位段落+4位段内，极性定义、最小单位及线路位反转依题目指定。

N路TDM每帧各1个b位样值、另有b_oh位开销时R_b=f_s(Nb+b_oh)。再经码率R_c编码和M进制映射，应继续除以R_c、log₂M，不能跳过中间级。

```text
D=Σᵢ∫区间ᵢ (x−yᵢ)²p_X(x)dx
yᵢ=E[X|区间ᵢ]；xᵢ=(yᵢ+yᵢ₊₁)/2
R_info=R_c R_slog₂M
```

## 11.3 熵、互信息与信源压缩

自信息−log₂p，熵是其平均，单位bit/信源符号。互信息是观察Y后对X不确定性的减少；它是联合分布的函数，不能简单用“正确收到的比特比例”替代。

二元前缀码满足Kraft不等式Σ2^{−lᵢ}≤1。Huffman反复合并最小概率，给出给定字母表的最优前缀平均码长；不同同权合并规则可给出不同但同样最优的树。现有W3可以操作概率与树。

```text
H(X)=−Σpᵢlog₂pᵢ，0log0=0
I(X;Y)=H(X)−H(X|Y)
二元最优前缀码：H≤L̄<H+1（通常非退化情形）
```

## 11.4 信道、容量与宽带极限

离散无记忆信道容量是对输入分布最大化互信息。BSC容量1−H₂(p)，p=1/2时为0，p=1时为1，因为确定翻转可以再翻回来。

AWGN容量C=B log₂(1+S/(N₀B))。固定S、N₀加宽B同时增加噪声功率，容量趋向S/(N₀ln2)，而不是无限线性增长。容量允许理想编码与输入分布，不能当作某个固定QAM的实际BER保证。

多径时延带来频率选择性，多普勒与时变带来相干时间变化；平坦/选择性和快/慢是两组不同维度。相干带宽、时间与时延扩展、多普勒的倒数是量级关系，具体系数取决于定义。

```text
C_use=max_{p(x)}I(X;Y)
C_AWGN=B log₂(1+S/(N₀B))
容量边界：E_b/N₀=(2^η−1)/η，η=R/B
η→0时极限ln2≈−1.59 dB
```

## 11.5 线性码、汉明码与CRC

线性(n,k)码有2ᵏ个码字，c=uG，GHᵀ=0，伴随式rHᵀ=eHᵀ。伴随式表示一个陪集，不唯一识别任意多比特错误；零伴随式也可能对应从一个合法码字错到另一个。

最小距离d_min用于检错时保证检测d_min−1个错误，用于纠错时保证纠正floor[(d_min−1)/2]个错误。普通Hamming(7,4)纠1错，双错可误纠；扩展校验的SECDED是不同结构。

CRC以GF(2)模二除法计算余式，用来检错，不是通用纠错器。未检出当且仅当错误多项式被生成多项式整除。次数r且首尾非零可检出长度≤r的突发错误；只有含(x+1)因子时才保证检测全部奇数重量错误。

```text
c=uG；S=rHᵀ
p(x)=xʳm(x) mod g(x)
c(x)=xʳm(x)+p(x)，所有加法为异或
```

## 11.6 卷积码、Viterbi与交织

卷积码状态由记忆寄存器决定，格图是状态图沿时间展开。Viterbi在每个状态保留最优累计度量路径，最后回溯，不能每步贪心判一个输入比特。

硬判BSC且p<1/2可用汉明距离；软判AWGN用欧氏距离或等价对数似然。它通常是序列ML，不等于逐比特MAP。尾比特占用有限帧速率，母码1/2不代表每个短帧有效信息码率恰好1/2。

交织把突发错分散到不同码字，代价是缓存和延时；它本身没有增加纠错冗余。现有W3提供固定(7,5)₈、K=3的短帧硬判格图，不是任意卷积码工具。

```text
Viterbi：M_k(s)=min_{s′→s}{M_{k−1}(s′)+d_branch}
有效码率=信息位数/实际发送位数
```

## 11.7 扩频、LFSR与码的相关

m级LFSR最大周期2ᵐ−1要求本原反馈多项式和非零初态。周期首尾相接后将0/1映为±1，m序列归一化周期相关为1（整周期位移）和−1/N（其他位移）；有限非周期片段不必满足同样结果。

Walsh码正交依赖同步对齐；多径和时移可能破坏正交。直接序列扩频的处理增益约R_chip/R_b，描述适当干扰抑制，并不在固定E_b/N₀的理想单用户AWGN中自动降低未编码BER。扰码也不等于加密。

```text
G_p≈R_chip/R_b
HHᵀ=NI
现有Clab采用固定三阶LFSR和有限周期相关模型
```

## 11.8 OFDM：频谱重叠仍可以正交

有用时长T_u决定子载波间隔Δf=1/T_u；每对子载波在整个有用窗内内积为零，所以频谱重叠并不妨碍正交分离。这与第1章旋转后积分抵消是同一结构。

CP复制符号尾部，长度须覆盖信道最大超额时延与定时裕量。去CP后满足条件时可把卷积看成循环卷积，FFT后Y[k]=H[k]X[k]+W[k]；CP不消除频偏、快时变或深衰落。

数据子载波、CP、保护频带、导频与编码均占开销。PAPR是时域峰值功率/平均功率，多载波偶然同相可产生大峰值；仅看IFFT采样点可能低估连续时间峰值。此项目前未在Clab实现，不用现有“频谱图”冒充OFDM实验。

```text
∫₀^Tᵤ e^{j2π(k−l)t/Tᵤ}dt=T_uδ[k−l]
R_info=N_dlog₂M·R_c/(T_u+T_CP)
```

## 13.1 期望线性，方差对系数平方

无需独立就有E[aX+bY+c]=aEX+bEY+c。方差则为a²DX+b²DY+2abCov(X,Y)。负号平方后不会让单个方差为负。

你提出过用D(Z₁+Z₂)反求Cov的路线，这是正确方法。若Z₁=2X+Y、Z₂=2X−Y，DX=DY=σ²且Cov(X,Y)=0，则两方差均5σ²，和为4X，Cov=(16−5−5)σ²/2=3σ²。

```text
Cov(Z₁,Z₂)=[D(Z₁+Z₂)−D(Z₁)−D(Z₂)]/2
Cov(aX,bY)=abCov(X,Y)
```

## 13.2 样本均值中同一个X₁不能当独立副本

独立同分布、方差σ²、Y=(1/n)ΣXᵢ时，DY=σ²/n，但Cov(X₁,Y)=σ²/n而不是0。故D(X₁−Y)=(n−1)σ²/n。
